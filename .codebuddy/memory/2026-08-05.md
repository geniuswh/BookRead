## 书源爬取失败修复

- 现象：书源管理点菠萝猫"爬取"报失败
- 根因：axios 全局 timeout 30秒，而菠萝猫书源爬取（首页20本×章节分页）需约351秒（未登录走 anti_block 延迟）
- 修复：
  1. 前端 `crawlSource` 单独设置 timeout: 600000ms
  2. 后端 `crawl_book_source` 对菠萝猫书源爬取前自动调用 `boluomao_login`（账号从环境变量 BOLUOMAO_USERNAME/PASSWORD 读取，默认 geniuswh@163.com/geniuswh）
  3. 登录后 parse 351秒→55秒（6.4倍加速）

## 爬取效率优化（借鉴第三方思路）

- 调研：Scrapy 并发、多线程/异步爬虫、限速平衡、增量爬取
- 应用优化（BoluomaoAdapter + crawl_book_source）：
  1. **线程池并发**：ThreadPoolExecutor(max_workers=5) 并发解析首页多本书（之前串行）
  2. **限速平衡**：分页请求间 sleep 0.1-0.2s
  3. **增量爬取**：crawl_book_source 注入 `_existing_urls`，已入库书籍跳过详细解析（parse 中直接返回 None）
- 效果：首次全量 34.5s（对比原始串行未登录 351s，约10倍）；二次增量 0.2s
- 剩余可优化空间（未做）：aiohttp 全异步、章节级并发、分布式/代理池
